# C Language Programs (Class 8–10)

Simple and easy-to-understand C programs, arranged topic-wise in
the same order as taught in class. Every program has a heading
comment that explains what it does, and short comments inside
the code.

## Programs

| No. | File Name | Topic |
|-----|-----------|-------|
| 01 | `01_hello_world.c` | First C program |
| 02 | `02_relational_operators.c` | Relational operators |
| 03 | `03_logical_operators.c` | Logical operators |
| 04 | `04_assignment_operators.c` | Assignment operators |
| 05 | `05_unary_operators.c` | Increment / Decrement |
| 06 | `06_if_cube_of_number.c` | if – cube of a number |
| 07 | `07_if_frame_shape.c` | if – portrait / landscape / square |
| 08 | `08_if_month_name.c` | if – month name (1 to 6) |
| 09 | `09_if_else_cheaper_product.c` | if-else – cheaper product |
| 10 | `10_if_else_civil_services_eligibility.c` | if-else – eligibility check |
| 11 | `11_if_else_if_month_name.c` | if-else if ladder – month name |
| 12 | `12_if_else_if_fever_level.c` | if-else if ladder – fever level |
| 13 | `13_switch_calculator.c` | switch – simple calculator |
| 14 | `14_switch_vowel_or_not.c` | switch – vowel or not |
| 15 | `15_nested_if_month_name.c` | Nested if – month name |
| 16 | `16_nested_if_leap_year.c` | Nested if – leap year |
| 17 | `17_while_odd_numbers.c` | while loop – odd numbers 1 to 99 |
| 18 | `18_while_multiplication_table.c` | while loop – multiplication table |
| 19 | `19_while_factorial.c` | while loop – factorial |

`exercise.txt` contains practice questions based on these topics.

## How to Run

```bash
gcc 01_hello_world.c -o program
./program
```
